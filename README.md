## New York's Covid Cases by ZIP Code (ZCTAs)
The map of New York shows colors of different intensity, the darker the color, the more cases of covid that were reported in each zip code images/MidtermMap1.png
**Question:** With my map, it's able to answer questions like "What were the Covid-19 rates like in a place so dense and populated like New York?"
**Data:** This map uses information and the feature layer "COVID19_ZCTS" made by ArcGIS Pro and published by the user GGA_Admin, https://www.arcgis.com
**Method:** While making this, I accessed the attribute table which allowed me to get more insight on the data I had in front of me. I sorted through the data and organized it by population, the count of covid cases, and the rate of covid rates. I then proceeded to apply this data onto the map by using a color scheme of a gradient scale
**A design choice I made and why:** When making this map, I had many ideas and wanted to include as much information I could without overwhelming but wanted to really get my point across with the difference in covid cases and rates. To achieve this I knew I had to use a gradient scale so readers could understand what they're looking at
**A limitation of this map:** What this map doesn't tell readers could be the density of essential workers, while I'm sure most of us remember what the pandemic was like, some people like my mother and sister still had to work. In a place like New York, this can be scary because of the dense population and the increased chances of catching covid
